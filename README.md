## 🔥 Featured Projects

### 🌦️ Mini Weather ETL Pipeline — `LIVE`
**Tech Stack:** Python, urllib, JSON, ETL, GitHub Actions, Logging

> Pulls live weather data for 16 cities from the Open-Meteo API (free, no key needed), classifies each reading (Hot / Cold / Normal), and appends records as JSON Lines to a flat file. Runs automatically every 6 hours on GitHub Actions — zero cost, zero manual intervention.

**Real bugs debugged in production:**
- Module-import side-effect bug — fixed with `if __name__ == "__main__"`
- Malformed blank-line crash in the file reader — fixed with graceful skip logic
- 403 permission error on the GitHub Actions git push step — fixed via workflow permissions setting
